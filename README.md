## 🚀 시작하기

### 1. 저장소 복제

```bash
git clone https://github.com/JUNGHWAN12/project.git
cd project
```

### 2. 가상 환경 생성 및 활성화

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. 실행

```bash
python hello.py
```
